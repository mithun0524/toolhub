    Frequently asked questions

    WebP is the safe default for the web: it is 25–35% smaller than JPEG at the same quality and every current browser supports it. Use AVIF when you want the smallest possible file and your audience is on recent browsers. Use PNG when you need lossless quality or transparency, and JPEG when a tool or service only accepts it.
    JPEG cannot store transparency, so transparent pixels must be filled with a solid colour. This tool lets you pick that colour — white by default — instead of turning it into unexpected black.
    Conversion uses your browser's own encoders. Chrome and Firefox can write AVIF; some Safari versions cannot. The tool detects what your browser supports and disables the rest, instead of silently producing a PNG with the wrong extension.
