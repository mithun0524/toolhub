    Frequently asked questions

    Making an image smaller keeps it sharp — this tool uses the browser's high-quality smoothing when downscaling. Making an image larger cannot invent detail that was never captured, so anything above 100% looks softer. That is why “never enlarge beyond the original” is on by default.
    With aspect ratio locked, every image is matched to your target width and its own height is derived from its own proportions — so portraits and landscapes both come out undistorted. Percentage mode scales each image relative to its own dimensions.
    It keeps the original width-to-height proportion, so typing a width fills in the matching height and the picture never looks stretched. Uncheck it if you deliberately need exact non-proportional dimensions.
